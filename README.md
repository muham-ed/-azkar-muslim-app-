# Azkar Muslim & Islamic Services App 🌙📱

A modern, elegant, and feature-packed Islamic companion app built with **Flutter** and **Dart**. Designed with a human-centric UI/UX, warm Islamic typography, dark/light theme support, offline data persistence, and interactive spiritual tools.

---

## ✨ Features

- 🤲 **Authentic Daily Azkar (أذكار المسلم)**: Complete Morning & Evening Azkar, Sleep Azkar, and Post-Prayer supplications with full diacritics (التشكيل التام) and authentic virtues (الفضائل الثابتة).
- 📿 **Digital Tasbeeh Counter (المسبحة الرقمية)**: Interactive circular counter with tactile haptic feedback, customizable target limits (33, 100, 1000), phrase selection, and lifetime total counter.
- 📖 **Holy Quran Reader (القرآن الكريم)**: Clean reading surface with Amiri font, Surah search filter, verse count, and revelation types (مكية/مدنية).
- 🕋 **Prayer Times & Qibla Compass (مواقيت الصلاة والقبلة)**: Real-time countdown timer for the upcoming prayer and live visual Qibla direction indicator.
- 🎨 **Human-Centric UI/UX & Dark Mode**: Modern Muted Emerald & Muted Gold theme palette with full Dark/Light mode toggle.
- 💾 **Offline Data Persistence**: Built using `shared_preferences` & `provider` so daily progress and counter stats are stored locally and never lost.

---

## 🛠 Tech Stack & Architecture

- **Framework**: [Flutter](https://flutter.dev) (Dart)
- **State Management**: Provider (`MultiProvider`)
- **UI/UX**: Material 3, Custom Emerald/Gold Islamic Palette, Google Fonts (`Cairo`, `Amiri`)
- **Local Storage**: `shared_preferences`
- **Haptics**: `vibration`

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muham-ed/azkar-muslim-app.git
   cd azkar-muslim-app
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
